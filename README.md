# Zamboni Escape (Work in Progress)
**Physics-Based Arcade Navigation & Evasion**

### 📌 Overview
Zamboni Escape is a high-stakes arcade chase game where "game feel" meets comedic tension. Players take control of a hockey player desperately navigating an ice rink to evade a disgruntled referee who has commandeered a Zamboni. The project focuses on the technical challenge of balancing momentum-based player movement against a heavy, destructive AI-driven hazard.

### 🛠 Technical Pillars
* **Engine:** Godot (GDScript)
* **Physics Programming:** Architecting custom character-controller logic to simulate the unique mass, friction, and slide constants of a player on skates.
* **Chase Mechanics:** Developing a weight-based collision and momentum system for the Zamboni to ensure it feels like a persistent, unstoppable threat.
* **Environmental Interaction:** Implementing event-driven triggers and obstacles that react to both the player's agility and the Zamboni's destructive path.

### 🚀 Development Status
* **Current Phase:** Mechanics Iteration & Physics Tuning.
* **Active Tasks:** Refining the friction-to-acceleration curves for "skating" physics and implementing the initial pathfinding logic for the Zamboni.
* **Next Milestone:** Integration of a "Close Encounter" pressure system and dynamic ice hazards.
